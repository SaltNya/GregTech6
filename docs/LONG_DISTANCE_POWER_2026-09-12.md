# 长距离电力端点实装

本批将空的 `LongDistanceTransformerBlockEntity` 接入原版 EU 能量包传输，新增五级端点支持和五级导线行为。不是完整物流系统或整个移植蓝图完成。

## 内容

- EV、IV、LuV、ZPM、UV 端点额定包大小为 2048、8192、32768、131072、524288 EU。输入/输出范围为额定值的一半至两倍。
- 原来的 `long_dist_transformer_ulv/lv/mv` 保留 ID，实际对应 EV/IV/LuV；新增 `long_dist_transformer_zpm/uv`。原版没有本项目旧名称暗示的 ULV 起步系列。
- 现有 `long_dist_wire_ev/iv/luv/zpm/uv` 从装饰方块变为真实线路，耐压为各级额定电压的两倍。旧通用 `long_dist_wire` 作为 EV 导线保留。
- 方向遵循原版：发送端正面接输入、背面接长距线；接收端正面接长距线、背面接耗能设备。无需设置坐标或预存能源。
- 每包扣除 `max(64, distance/8)` EU，保留原始包正负号。实际消耗包数由末端设备接受数决定；没有接收设备则不消耗正常电压的包，也不创造可再次拉取的库存。
- 模拟只验证线路与电压条件，不实际输电、烧线或损坏端点；这一点沿用原版“不进一步模拟末端需求”的语义。
- 已连接线路的低压包按原版根接口消耗但不输出；导线过压烧毁线路，端点过压移除故障端点。
- 软锤切换停机，停机状态写入 NBT。路线不序列化，重载后重新发现。
- 使用原版端点底色/覆盖纹理，五级外壳分别使用铬、钛、铱、锇、Trinitanium 颜色；物品和放置方块共用材料入口。素材哈希记录在 `tools/gt6_texture_sources.json`。

## 扩展与差异

- 扫描限定已加载区块，最多 4096 个导线方块；缓存成功线路及相邻位置的方块状态。断线、转向和新增分支会使缓存失效。不会强行加载区块。
- 同一线路要求同一注册导线方块；同等级不同 ID 也不能混接。当前按一发送端、一接收端校验，多端点网络拒绝输电，避免原版查找顺序造成的不确定选路。
- 原版 16 种材料导线尚未全部细分，目前提供五个电压等级。路线距离采用到接收端的最短导线层数。
- 当前只提供水平朝向；专用运行/闪烁贴图、完整工具提示和 Jade 线路状态还未接入。
- 端点过压采用移除故障块，尚未还原原版全部爆炸、声音和粒子表现。不会把这一处理记作原版故障机制完整还原。
- 末端目前接 GT `IEnergyBlock` 设备；第三方电力兼容桥及整套制作路线尚待补齐。因此先用创造模式验收，不能宣称生存闭环完成。
- 状态缓存验证仍需遍历线路邻域；未做数千格线路的客户端/服务器性能实测。

## 创造模式测试

1. 取两个 EV 长距离变压器端点和若干同一种 EV 长距离导线。全部端点朝西摆放：左端点背面（东）接导线，右端点正面（西）接导线。
2. 左端点西面接 EV EU 供给，右端点东面接可接受相应包大小的 GT 设备。短线输入 2048 EU 包，输出应为 1984 EU 包，包数由末端需求决定。
3. 依次测试更高等级端点和对应导线；不要把普通低压机器接在高压输出后面。
4. 拆除中间导线应停止；补回立即恢复。增加第二个接收端应停止，拆掉多余接收端后恢复。
5. 用软锤停机，退出重进应仍停机；再次软锤后恢复。检查四个朝向的纹理及背包材料颜色。
6. 单独搭一条测试线路，用 IV 电压输入 EV 导线，执行输电时导线应烧毁。模拟测试由自动测试覆盖。
