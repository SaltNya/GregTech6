# 生存加工与配方续批（2026-09-13）

## 本轮实现

新增 430 条实际机器配方，分为纺织染整、橡胶/胶水上游、生存用品三个独立模块。均注册进真实 RecipeMap，使用现有机器执行和 JEI 显示，不是仅供展示的假配方。本轮未构建 JAR，未复制 GTM 代码。

### 纺织染整：331 条

- 234 条染色：三种染料体系 × 16 色，支持陶瓦、玻璃和玻璃板；非白色另有白羊毛、白地毯染色。原版 144 mB 标准染料量按比例向上取整：羊毛/玻璃/陶瓦 9 mB，地毯 5 mB，玻璃板 4 mB。
- 78 条氯气脱色：有色羊毛、地毯恢复白色；染色陶瓦、玻璃、玻璃板恢复无色版本。氯气分别消耗 50 / 25 / 50 / 50 / 20 mB。
- 4 条甘蔗水浴造纸：普通水、矿泉水、灵露各 125 mB；蒸馏水 100 mB。均 16 ticks、0 GU/t。
- 15 条织布机配方：羊毛、蜘蛛网、纸、四件皮甲、四件钢环锁链甲、铁/金/钻石马铠以及鞍。羊毛/纸使用 0 号选择器，蜘蛛网使用 1 号，护甲依头/胸/腿/脚使用 4/5/6/7 号。选择器不消耗。

来源：原版 Loader_Recipes_Vanilla.java 717–767；染料标准量来自 Loader_Fluids.java，水量重载来自 FL.waters。

### 橡胶与胶水上游：21 条

- 黏液球挤压得到 250 mB 绿色黏液，榨汁得到 125 mB；64 ticks、16 GU/t。
- 三种黏液的离心：250 mB 黏液 → 72 mB 乳胶 + 250 mB 胶水；64 ticks、16 GU/t。
- 三种黏液与烈焰粉/整份烈焰粉尘混合，得到岩浆膏，保留单份和九份批量配方。
- 岩浆膏、黏骨粉离心回收黏液及对应固体。
- 橡胶树脂挤压、榨汁、离心、四种水混胶水，以及层压黏性活塞，共 8 条。

生存可用的确定上游是原版黏液球；其乳胶产物能直接进入现有凝固机：16 mB 乳胶 → 1 橡胶粒。橡胶树脂的加工路线已补，但现有树液袋仍是未完成行为的工具方块，本轮不宣称树脂野外采集已经闭环。

来源：原版 Loader_Recipes_OreDict.java 的 slimeball 监听器，Loader_Recipes_Other.java 的 itemResin 监听器，Loader_Recipes_Vanilla.java 902–908。

- 16 色羊毛织画、皮革和木棍织物品展示框，共 17 条。

- 3 曲面铁板卷制铁桶；石头/石砖凿刻，共 3 条。
- 4 件皮甲切片回收皮革，回收量为 1/2/2/1，分割刀片保留。

来源：原版 Loader_Recipes_Other.java 200–218，Loader_Recipes_Vanilla.java 638–641、770–774、876–903。

- MaterialFactories.wood 恢复 DUST/GENERATE_DUST。原版 TD.ItemGenerator.G_WOOD 明确包含 DUSTS，先前工厂漏掉后所有木材都没有粉末形态。
- 只恢复 Sugar 的 gemChipped 例外，依据 OP.gemChipped.forceItemGeneration(MT.Sugar)。没有把糖改成完整宝石材料。
- 新配方遵循原版对应物品：糖、火药、骨粉、烈焰粉、金粒采用 Minecraft 物品，避免生存掉落无法匹配模组重复物品。

## runClient 建议验收

1. 黏液球 → 挤压机 → 250 mB 黏液 → 离心机 → 72 mB 乳胶和 250 mB 胶水。乳胶送凝固机，检查橡胶粒与剩余流体量。
2. 甘蔗 → 浴盆/浴槽 + 水 → 纸；或织布机放 0 号选择器和甘蔗。选择器必须保留。
3. 织布机用 4 根线 + 0 号选择器得到白羊毛；切换 1 号得到蜘蛛网。用 6 皮革 + 2 钢环 + 3 钢棒制作鞍。
4. 上一轮花染料/化学染料放入浴槽：用白羊毛、白地毯、玻璃和玻璃板验收染色。再用氯气脱色。JEI 查氯气来源时选择实际流体对应条目。
5. 普通糖、蜘蛛眼、棕色蘑菇放入搅拌机制作发酵蛛眼；普通金粒和西瓜片制作闪烁西瓜片。
6. 沙子 + 0 号选择器 → 电解机 → 二氧化硅粉，与石粉、黏土粉接上一轮泡沫混合配方。
7. 皮甲 + 分割刀片 → 切片机 → 皮革，确认刀片没有消耗。
