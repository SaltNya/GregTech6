# 导线加工、聚合物成型、模具与石墨烯纳米制造续批

本批对照原版 GT6 `Loader_Recipes_Handlers`、`Loader_OreProcessing`、`MultiTileEntityWireElectric`、`MultiItemTechnological`、`Loader_Recipes_Other` 与化工导入数据。未搬用 GTM 代码。新增配方数量按材料与规格展开统计，不能换算为全模组完成率。

## 已实现的制造流程

### 导线与绝缘

30 种已注册导线材料接入工作台编织、拆分及 1x/2x 橡胶板绝缘，共 1320 条工作台配方。编织要求同种材料、同种输入规格，输入数量不能超过九格；因此 1x 到 10x–16x 需要先加工中间规格或使用织布机。每条配方保持导体材料总量。

机器配方通过 `GTWires` 的现有方块定义解析材料和规格，替换旧 `wireGt01` 前缀查询失效的路径。可锻造导线材料增加锭到两根 1x 线的拉丝流程；SOFT/FURNACE 对应材料使用 16 ticks，较难加工材料使用原版质量系数耗时。石墨烯从纳米制造获得，未添加石墨烯锭拉丝捷径。

织布机支持 1x–16x 的全部整除编织组合，选择电路编号等于目标规格；保留电路而消耗原料。耗时为 `32 × 目标规格 × (材料质量 + 1)` ticks，16 GU/t。

拆包机固定拆为 1x，16 ticks、16 GU/t。原版多个相同输入的拆分候选在新配方系统里无法唯一选择，因此保留其最先注册的 1x 结果，避免随机产不同规格。可再编织成目标规格。

覆膜机支持 1x/2x/4x/8x/12x 电缆，分别消耗 1/1/2/3/4 块橡胶板，或四倍数量的橡胶箔。16 GU/t，耗时随胶层材料量为 16/16/32/48/64 ticks。现有 16x 绝缘电缆是早期移植扩展，GT6 这组原版注册没有对应项，本批未编造其包覆配方。已保留其存档 ID。

### 模具

补入普通与低温两套挤压模具制造树，共 64 条工作台配方。普通坯料用二重碳化钨板；低温坯料用二重钢板。锤、锉、剪线钳按各自耐久扣费并保留，坯料/旧形状模具在切制新形状时被消耗。

增加 `allow_mirror` 有序工具配方选项。模具配方关闭镜像，仍允许整体在网格中平移；剪线钳的相对方位决定形状。该选项包含在服务端到客户端配方同步数据中。现有其他工具配方保留默认匹配行为。

补回漏注册的低温小齿轮模具及中英文名称。贴图直接复制原版 `gt.multiitem.technological/10226.png`。

### 橡胶、塑料与化工催化剂

新增 93 条机器配方（含原有完整齿轮路线，未在替换通用配方时删掉）：16 mB 乳胶凝成一粒橡胶，0 GU/t、256 ticks；橡胶/塑料粉与锭使用普通或低温模具挤成锭、板、杆、长杆、螺栓、环、箔、弯曲板、小板、细线、小齿轮、齿轮。按原版 EXTRUDER_SIMPLE 用 16 GU/t、每单位材料 64 ticks，并保留模具；完整齿轮消耗四份粉/锭、256 ticks。相同形态到自身的无效配方不注册。

四条工作台配方支持橡胶、塑料粒与锭的九比一互换。旧通用挤压器不再为这两种材料注册错误的 16-tick 快速版本。

修正生成化工配方中显式数量为 0 的物品输入：显示为一个物品，但登记为配方催化剂，不再被消耗。塑料合成中的氯化镁、铂等相关催化流程因此恢复保留规则；正数量输入仍消耗。塑料粉可继续接低温挤压成锭、板，再接上一批电路板制造。

### 石墨烯纳米制造

补入原版 45 条碳粉分量/批量变体配方。选择器 0–12 分别生产箔、板、弯曲板、外壳、细线、1x 导线、螺栓、杆、长杆、环、小齿轮、齿轮、转子。消耗碳并保留选择器，时间和原料数量照原版表；转子按 4.25 单位材料计算。

## 游戏内测试清单

1. 从铜锭拉丝得到两根 1x 铜线；工作台或织布机编到 4x、6x、16x，再用拆包机拆回 1x，核对总量。混合铜线与金线不应合成。
2. 织布机选择电路设为目标线宽。移走/改错选择器不能继续该配方，正常加工不消耗选择器。
3. 用一块橡胶板分别包覆 1x/2x 铜线；用两块板或八片箔包覆 4x，确认材料扣除。较粗规格使用覆膜机。
4. 低温模具坯料开始，照 JEI 的剪线钳位置切制不同形状；左右镜像应得到相应不同形状或不匹配。检查所有工具扣耐久、旧模具被消耗。
5. 凝固机放入乳胶，16 mB 得一粒橡胶；九粒合成锭。用低温板模具挤出橡胶板，再做电动泵和传送带。
6. 塑料化工配方使用氯化镁催化剂，检查加工后催化剂保留。塑料粉用低温锭模具成锭，再用低温板模具成板。
7. 纳米制造机分别用选择器 0、5、12 测试石墨烯箔、导线、转子。选择器保留，物料总量应对应原版配方。

## 验证与剩余边界

Forge 启动实际登记 1796 条导线加工、93 条聚合物成型、45 条石墨烯纳米制造机器配方。另有 1320 条导线工作台、64 条模具、4 条粒锭互换配方；合计新增 3322 条配方，数量主要来自材料/线宽组合。

最终复测 81 项 Forge GameTest 全部通过。新增五项批量测试覆盖全部工作台导线的实际匹配与材料守恒、全部模具的方向唯一性与网络同步、模具制作时工具损耗/坯料消耗、机器导线配方材料守恒和选择器保留、石墨烯碳量守恒、聚合物成型扣料，以及塑料化工催化剂并行保留和粉到锭到板的衔接。

独立注册检查通过：材料注册、模型查找、工具交互、活塞能源、容器/传感器与存储状态契约均通过。

59 项 Python 测试通过，包含模具模型/贴图引用、导线配方数量守恒、原版低温小齿轮贴图逐字节核对。

没有启动可视客户端，JEI 布局、拖动与实际渲染仍需游戏内验收。

本批不是全量高科技/核能/生态移植。全部 ANY 橡胶/等价金属替代、全部挤压热加工与温度耐性、多种材料模具、线缆回收绝缘层仍需继续核对。工作台拆分和拆包机统一为 1x；原版其他拆分目标未重复注册。

导线拉丝使用当前移植材料的可锻造分类，不能据此认为所有原版材料处理条件已对齐。原版无对应项的 Netherite、泛 Superconductor 单线生产未新增；这些现存导线仍可使用规格整理。原料矿物、所有化工上游及完整生存路线仍需后续逐链验收。
