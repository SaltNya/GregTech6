# 原版方块加工与木材生存链续批（2026-09-13）

## 本轮实装

本轮新增 1,398 条可执行机器配方：原版方块加工 974 条、木材加工 424 条。统计包含冷却液变体；合并同一加工路线的冷却液选择后为 416 条机器处理路线。上一轮的 396 条原版材料粉碎回收与 26 条车辆装拆仍保留。

- 锤碎 / 粉碎机：蘑菇块、石英块与楼梯半砖、石砖及裂纹变体、石头→圆石→沙砾、砂岩、冰、硬化黏土、全部染色玻璃及玻璃板、萤石。原版 RM.smash 的锤碎为 16 ticks，粉碎为 32 ticks，均 16 GU/t。
- 切割机：17 种玻璃→对应玻璃板，16 色羊毛→地毯、16 色床→木板及对应颜色羊毛，石材切半砖、平滑石材切石板，西瓜切片并返回种子。
- 木制品拆解：十种木材的按钮、压力板、门、活板门、栅栏门、告示牌，以及八种船；工作台、书架、箱子、陷阱箱、音符盒、唱片机、画、展示框、梯子。书架返回书，陷阱箱返回绊线钩，唱片机返回钻石。带库存 NBT 的容器不能进入切割配方。
- 压力清洗：苔石、苔石砖去苔。
- 木材生存链：橡木、云杉、白桦、丛林、金合欢、深色橡木、红树、樱花的原木 / 木头 / 去皮变体。原木切出六块木板和树皮；去皮木切出七块木板和木粉；清洗去皮并回收树皮；车床制长杆和木棍；木板切半砖、楼梯切半砖并回收小堆木粉。
- 焦炉：原木→木炭 + 250 mB 杂酚油；去皮木→木炭 + 200 mB 杂酚油。沿用 GT6 3600 ticks、0 GU/t 的配方参数。树皮可直接进入此前的浸洗造纸路线。

## 冷却液与框架

统一 `SawingCoolants` 定义，并接入 `MachineRecipeMaps.sawing` 公共注册入口：水、灵泉、矿泉水为四倍耗时 / 用量，蒸馏水为三倍，两种已注册润滑剂为一倍。食物切割不生成润滑油配方。

新配方通过具名批次注册；缺失材料形态或配方冲突会报告具体源行名称并停止加载，不静默跳过。机器与 JEI 使用同一配方表。

## 为现代版本作出的调整

- 石英楼梯回收四个石英，不沿用旧版六个。1.20.1 切石机可以一块石英块制作一格楼梯；旧产量会刷材料。材料组成、粉碎和坩埚回收也统一限制为四单位。
- 木材组成采用 GT6 WoodEntry / BeamEntry 最终定义，覆盖早期默认数值：原木为八单位木材加一单位树皮，去皮木为八单位木材。前一轮四单位原木的临时映射已移除。
- 告示牌为 13/6 单位木材、梯子为 7/6，按现代三件一批的合成数量计算，与切割拆解返回物一致。
- 旧版无颜色区分的床推广到现代 16 色；旧版六种原版木材规则推广到红树、樱花。去皮原木作为现代对应物使用，并不是新增 GT6 横梁方块。
- 通用家具无保存树种信息时仍返回橡木木板；显式带树种的方块返回自身木板。

## runClient 建议验收

1. JEI 查询玻璃用途：应有六种切割冷却液选择；水 200 mB / 128 ticks，蒸馏水 150 mB / 96 ticks，润滑油 50 mB / 32 ticks，产出九片玻璃板。测试冷却液不足时机器不吞物品。
2. 查询红色玻璃、蓝色羊毛和蓝色床：输出应保留颜色；西瓜只能使用水类冷却液。
3. 查询原木用途：测试切板、清洗去皮、车床和焦炉；拿树皮接浸洗造纸，杂酚油接已有下游。
4. 拆书架、陷阱箱、唱片机，检查副产物；通过保存库存 NBT 的箱子物品验证它不会被直接拆解。普通生存箱子若破坏时已掉出物品，其空箱物品可以正常拆解。
5. 用切石机将石英块做成楼梯，再锤碎 / 粉碎 / 坩埚回收，不能得到六单位石英。
6. F3+H 查看原木、去皮木、告示牌和梯子的组成。

## 尚未完成

这轮不是“所有原版方块都已完整还原加工”的声明。已有全物品组成分类不等于每种物品都已经具备安全的回收 / 再制造链。

- 现代竹材、下界木材尚无完整去皮、焦化链；下界木材未套用会生成木炭的普通木材配方。
- 木材手工锯 / 锉配方、削减原版徒手产量的 GT6 配置、完整 GT6 横梁及专属树种材料仍需继续。
- 现代深板岩、铜氧化 / 上蜡、紫水晶、海晶、潜影盒等有材料分类，但完整加工和内容物保留规则还没有逐族还原。
- 苔藓生长、萤石宝石板和长杆等 RM 辅助注册分支尚未全部补齐。
- 全配方来源覆盖审计、原版全部动态配方、化工回收、跨模组等价材料仍有缺口；本轮没有宣称解决其他高科技 / 核反应堆系统的完整性。
