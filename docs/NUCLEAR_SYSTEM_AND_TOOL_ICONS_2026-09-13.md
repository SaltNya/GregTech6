# 核反应堆集中移植与 JEI 工具默认外观

## 工具显示

根因是 `GTToolBakedModel` 对无材料 NBT 的工具返回基础模型，而此前所有基础模型都引用铁镐。此次替换全部 37 种工具的基础模型：锤头、锯片、锉刀、螺丝刀及手柄按对应 GT6 素材组合；扳手、剪线钳等使用各自 iconset。没有给配方展示工具添加假材料 NBT，也不会让展示用空工具变成可用成品。已有组装工具继续按实际材料染色。每个默认模型最多五层，符合原版生成物品模型限制。

## 本批核反应堆实现

依据原版 `Loader_MultiTileEntities` 9201–9441、`MultiTileEntityReactorCore1x1/2x2`、各 `MultiTileEntityReactorRod*`，以及 `UT.Entities.applyRadioactivity`。未复制 GTM 实现。

- 原版 46 种棒定义：空棒、燃料棒、枯竭棒、中子吸收/反射/慢化棒、增殖棒及产物棒。定义包含材料、自发中子、发射量、反馈除数、最大通量、长整数寿命、目标产物及逐面中子损失。保留 6 个已有且能对齐原版的燃料棒 ID，其余新增 40 个 ID。
- 更正核心含义：1×1 是一根棒，2×2 是一个方块内部的四根棒，后者不再要求旧的虚构 3×3×3 外壳。旧外壳方块仍保留。
- 每秒进行两阶段中子交换，发射只读上一周期结果；内部相邻棒、水平邻接核心、1×1 与 2×2 的半宽接触均参与。没有加载的区块不被强制加载，未更新的核心不参与本次交换。
- 中子反射、吸收双倍产热、慢化棒按上一周期接触数反射、慢化传播、增殖逐面扣除损失和拒绝慢化中子已接入。燃料按中子上限加速损耗，水慢化时额外四倍损耗。枯竭后产生可回收的枯竭棒，增殖完成得到原版指定产物。
- 使用长整数寿命，支持原版 120 亿耐久，不再使用固定一小时寿命及 32 HU/t 常量。
- 11 类冷却规则：蒸馏水、工业冷却剂、熔融锡、熔融钠、半重水、重水、氚水、氯化锂、二氧化碳、氦、钍盐。冷却剂影响发射、反馈、上限及产热。按精确流体身份识别；普通水不再作为蒸馏水使用。
- 热量按原版单位转换成蒸汽/热流体或钍盐反应产物，不直接向邻居凭空发送 HU。先模拟完整输出容量，成功才扣冷却剂；余热保存，输出可被管道抽走，也尝试向出口方向推送。
- 输入 64000 mB，常规输出 64000 mB，蒸汽输出可达 10240000 mB。自动化只抽输出，手持容器可在输出为空时取回输入。
- 冷却不足、热出口堵塞或活跃干烧时销毁已装入的棒、停机并产生辐射/音效。遵循原版此处注释状态，不开启破坏地形的爆炸。
- 辐射接入原版没有 IC2 辐射药水/食物跟踪器时的备用效果：缓慢、挖掘疲劳、反胃、虚弱、饥饿、凋零，持续时间累加；亡灵与节肢类豁免。四件防护装备需均在 `gregtech:radiation_protection` 标签内，目前标签为空，未假设普通护甲能防辐射。
- Jade 显示棒数、中子、产热、积热、流体、启停和待取旧棒；新增中英文配置翻译。盖革计数器从目标核心读取实际中子数。
- 棒使用原版现有模型在核心内显示：4×16×4 像素，从 y=1 到 y=17；四棒分别位于四个象限。2×2 顶部四个点击区域与槽位一致。四槽核心扳手调用现有水平转向框架调整出口方向。
- 47 条原版制造/回收配方：装罐、增殖棒填充、枯竭及增殖产物离心、氚提取、锆空棒挤压。补回原版装罐明确使用的棒形态。
- 修复材料流体生成器不能同时生成气/液态的问题，恢复水同位素液态并保留已有气态 ID。

## 存档与操作变化

- 新放置与从旧格式读入的核心默认停机。装好冷却剂后用软锤启动；再次使用软锤停机。
- 空手查看状态，撬棍或潜行空手取棒。旧存档超出新槽位数的棒放入独立保留区，优先取出；拆除时同样掉落一次。
- 旧 1×1 中直接装入的铀金属棒保持原物品可取回，不免费转换成带锆外壳的新燃料棒。
- 旧 MOX、Am-243、普通 Naquadah 实验棒 ID 保留，但尚无已核对的对应原版定义，本批不编造参数，隐藏于创造目录并保留旧存档可取回性。原版富集硅岩与超能硅岩燃料棒使用各自新定义。
- 拆除时棒单独掉落，冷却剂、热流体和积热保存在方块物品 NBT 中；再放置保持停机。
- 原本把核心当 HU 发电机、把 2×2 核心当 3×3×3 多方块的测试装置需要按上述规则重新连接。

## 本批验收步骤

1. JEI 工作台配方中检查锤、锯、锉刀、扳手、剪线钳，默认图案各自正确且不附加材料颜色；再看实际组装工具的材料颜色是否保留。
2. 创造拿 1×1 核心、U-235 燃料棒、蒸馏水与软锤。注入蒸馏水、装棒、启动，Jade 应显示中子与产热，输出出现蒸汽；普通水注入应拒绝。
3. 并排放两个单槽核心，分别装 U-235 并启动；第一周期每个核心应从孤立时的 32 中子变为 64，后续有反馈增长。停掉邻居后回落。
4. 放 2×2 核心，不搭旧外壳。在顶部四个象限装棒，确认模型位置。单根 U-235 加一根相邻反射棒，首周期为 64 中子；四根 U-235 首周期各为 96。
5. 分别检查慢化棒、吸收棒、增殖棒的配方与说明。增殖损失阈值较高，不要因低通量下进度不动就判为失效；慢化中子不能用于增殖。
6. 保存重进、停机取棒、拆除重放，确认燃料剩余寿命与流体不丢失、不复制。
7. 创造测试干烧或堵塞热出口：应损坏装入的棒并停机，周边生物可能受辐射，核心方块不爆破地形。正常运行测试请接通热流体输出。
8. 盖革计数器面向核心，比较读数与 Jade 中子数。核对 Jade 设置页面不会出现缺失翻译错误。

## 尚未等同于原版全部核系统

- 单槽核心出口仍固定朝北；原版两个独立流体方向、输入超过半罐后向第二方向转移及全部工具面交互尚需对齐。
- 原版核食物/人体辐射跟踪器、跨模组防化服识别、专用辐射药水没有完整移植，本批采用原版备用药水分支和可扩展装备标签。原版的射线穿铅/水屏蔽也仍是 TODO，未虚构实现。
- 核心所有制造前置和材料全上游尚未闭环；本批棒配方完整加载，不代表核心及全部上游都有生存获取路线。
- 棒的放置方块行为、材质细节、内腔流体体积显示及全部图层/玻璃视觉仍需客户端验收和进一步对齐。服务器测试不能验证 GPU 渲染。
- 六个旧可对应棒的寿命从旧健康比例转换，无法恢复旧版本未记录的真实历史中子剂量。

## 后续按六个大阶段组织

这是把工作集中到较大的可验收功能批次，不是把以前 24–45 个中等批次的工作量直接删成六分之一。目标是每阶段贯穿定义、运行、配方、展示和回归测试，尽量减少只补一个小功能的轮次。

1. 核反应堆与高科技运行基础：本批完成核系统主体，剩余核接口/制造路线及高科技特殊规则继续核对。
2. 物流核心、无线/高级延伸器、USB/HDD 与覆盖板控制：集中完成数据与物流实际运行链。
3. 多方块完整系列及能源边界：材料等级、端口、故障、机器制造路线和显示统一验收。
4. 世界与生态：矿脉岩层、植物树液、蜂箱遗传和泡沫，按完整玩法链整批推进。
5. 材料配方全集、工具容器：动态配方、等价输入、化工回收、修理附魔和饮用计量等。
6. 生存闭环与跨系统验收：从早期工具到高级机器的实际路线、存档、多玩家和客户端回归。

力争按约 5–6 个大阶段推进主要功能，但目前不能保证只需 5–6 次回复就全部完成。核配方这次就揭示了多处材料/流体缺失；后续应以实际功能验收决定是否需要追加批次。完整还原的目标保持不变，未验证内容不记为完成。
