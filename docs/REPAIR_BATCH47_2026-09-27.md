# 第四十七批：高级养蜂箱配方与温湿度读取

## 原版依据

GT6 `Loader_MultiTileEntities.java:2222`：高级养蜂箱的形状为 `PRP / HBH / PCP`，P=不锈钢板，R=杂交蜂巢，H=1000 L 蜂蜜容器，B=普通养蜂箱，C=箱子。`MultiItemFood.java:237-247` 将黏土、黏性、皇家、灵魂、失忆、军事、炽热、冰冻、气流、岩土十类蜂巢归入 `beeCombCrossbred`，普通蜂蜜蜂巢不属于此组。

`MultiTileEntityBumbliary.java:299-315` 的温度计工具可从任何面读取缓存的温度和湿度，不调用开盖的繁殖惩罚或蜂后攻击。`MultiItemRandomTools.java:528` 注册水银温度计为该工具行为。

## 实现

- 新增高级养蜂箱的原版形状配方及十类杂交蜂巢标签。
- 复用已注册的 `finite_fluid_container_1000` 配料。两只容器必须各自真实装有至少 1000 mB 蜂蜜，拒绝无限/展示流体和不足量容器。
- 在 `ToolShapedRecipe` 中为定量流体配料返回扣液后的原容器，按实际匹配的偏移和镜像位置处理，不修改合成输入栈。普通工具的耐久与返还逻辑保留，不含定量流体配料的配方跳过这段处理。
- 普通和高级养蜂箱响应水银温度计，显示 K 温度及原版 0–1 湿度值；新增中英文消息，读取不干扰繁殖。
