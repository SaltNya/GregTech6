# 第四十六批：养蜂箱蜂勺操作和普通型生存配方

## 原版依据与改动

- GT6 `MultiTileEntityBumbliary.java:282-313,389-495` 和高级型对应实现区分普通界面与蜂勺界面；`Slot_Base.java:92` 先检查机器槽位限制，再检查创造模式或界面取出标志。原先移植版混用了两套规则：普通模式允许取回公主蜂，但蜂勺没有打开界面的行为。
- 现在用可用蜂勺右键顶部打开蜂勺模式；创造玩家也使用该模式。普通模式锁住繁殖蜂槽，蜂勺模式允许取回公主蜂、主雄蜂和备用蜂，工作中的活蜂后仍受机器规则限制。两种型号共用模式数据同步，客户端会收到正确权限。插入规则不变，仍仅允许公主蜂与雄蜂进入指定槽。
- 蜂勺按 GT6 的 10000 工具点击成本损耗，使用正确的主手/副手槽。生存玩家开盖仍触发 6000 tick 繁殖延迟和上一批接入的蜂后防御。
- 按 `Loader_MultiTileEntities.java:2221` 加入普通养蜂箱配方：`PPP / PBP / TdT`，P=处理木板、B=GT 野生蜂巢、T=ANY.Iron 螺丝、d=螺丝刀。使用 `tool_shaped` 返回磨损后的工具。
- 从已有 `MaterialGroups.Iron` 成员生成 `gregtech:screws/any_iron_or_steel` 标签，引用实际存在的 Forge 螺丝材质标签，因此包括原版 ANY.Iron 的铁/钢家族，避免只接受普通铁。

## 游戏内检查

1. 生存模式打开普通或高级养蜂箱，普通点击不应取回繁殖蜂槽中的蜂。
2. 用有耐久的蜂勺右键顶面，可取回公主蜂和雄蜂，也可 Shift-click；正在工作的蜂后不能强行取出。
3. 创造模式无需蜂勺即可使用取出模式；关闭后切到生存普通打开，检查权限恢复。
