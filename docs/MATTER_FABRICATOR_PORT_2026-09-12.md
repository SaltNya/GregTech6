# 物质制造机实装续批

本批推进大型物质制造机、五级小型物质制造机及其配方与制作路线。完整高科技系统和整个移植蓝图仍未完成；本批没有重做核反应堆、物流核心或世界生态。

## 实现范围

- 大型物质制造机 `largemassfab_lead` 改为原版 5×5×6 结构：97 致密铅墙、26 大型锇线圈、16 通风组件、1 通用四核处理器、4 控制四核处理器、4 转换四核处理器，加主控与中心空气。
- 主控位于底层前侧中央；内部 3×3×3 锇线圈壳的中心必须为空。顶层外围为通风组件，中央为通用处理器，其余八格允许控制/转换处理器互换，数量必须各四。
- 铅墙和锇线圈提供物品、流体和 QU 输入接口；顶层通风与处理器不提供接口。主控底部自动输出，结构破坏后已绑定端口立即停止工作，不强行加载区块。
- 大型机接受 1–2097152 QU 能量包，效率 100%，支持原版廉价超频和最多 64 路并行时长处理；缺能量保留工作进度。原料、待产物和进度使用公共机器执行器持久化。
- 小型机补齐 T1–T5，额定输入依次为 32/128/512/2048/8192 QU，效率为 50/62.5/75/87.5/100%。外壳统一为原版锇铱合金，硬度与抗爆参数为 16；后面接能，物品左进右出，流体上进下出，断电保留进度。
- 为兼容现有存档，T1 保留旧 ID `massfab_osmium`，实际材料和名称已改为锇铱合金；新增 T2–T5 的 ID 为 `massfab_osmiridium_t2` 至 `massfab_osmiridium_t5`。
- 元素分离依据原版质子、中子数生成：每个核子 131072 QU，输出对应 mB 的带电/中性物质。仅为当前已注册的有效元素形态及绑定流体生成，合金不当成元素处理，别名去重。
- 补入原版双锂和远古残骸的 28 条特殊末影转换定义，保留选择电路、时间、数量及原版不同形态的倍率。
- 补入主控、线圈、转换处理器和五级小型机的八条工作台配方；致密铅墙通过四块致密铅板焊接获得。锇线圈配方暂省略原版剪线钳工具槽与损耗。
- 三类新部件使用原版分层贴图和材料染色，来源哈希记录于 `tools/gt6_texture_sources.json`。JEI 展示完整三维结构和全部六类部件数量，保留拖拽、缩放、分层；Jade 复用现有多方块提供器，无新增配置 UID。

## 创造模式验收步骤

1. 搜索大型物质制造机，在 JEI 多方块装配页按分层预览搭建。检查六类部件数量、模型和四个朝向，Jade 应报告结构完整。
2. 交换顶层控制与转换处理器的位置，结构应保持完整；改为五个控制、三个转换，或堵住中心空气，应失效。修复后应恢复。
3. 从墙体输入一个铁锭和 QU。大型机累计 7340032 QU 的有效工作应产出 **26 mB 带电物质 + 30 mB 中性物质**。可分七次输入 1048576 QU 并各推进一个 tick；实际线路应使用可承受该包大小的设备。
4. 测试 EU 被拒绝，断电/退出重进后工作保留；拆墙停止、补墙继续，输出堵塞后清理应只得到一份产物。
5. 测试主控底部输出及墙体物品/流体交互。使用真正的流体容器和管道，展示流体物品不是可消耗的流体容器。
6. 搜索五级锇铱合金物质制造机，核对制作路线、材料颜色、额定 QU 和同一配方的效率差异；检查四个朝向的物品左进右出、流体上进下出。
7. 用双锂粉与选择电路 0 检查末影转换配方：10368 ticks、16 GU/t，输出 103680 mB 末影流体。通用 JEI 能源统计继续显示 GU，机器实际接受 QU。

## 边界与后续

- 元素配方覆盖当前已存在且可映射的物品/流体；未注册形态、未绑定到材料的流体别名仍需随材料全集补齐。未宣称原版所有材料链已经完成。
- 共用机器 GUI 和端口外观仍有原版专用提示、结构运行动画及面遮罩细节待核对。
- 本批给这些设备补入了制作配方，但上游高级元件、QU 供给全链及所有材料获取路线尚未完成生存验收。
- 核反应堆的完整中子/冷却/辐射机制、物流核心、其他多方块等级、工具容器与生态等剩余范围继续见大蓝图。
- 服务端测试不能代替客户端 GPU 渲染、鼠标交互或实际生存游玩的验证。本批未运行手动客户端验收。
