# 电动部件与电路制造链续批

本批对照 GT6 `MultiItemTechnological.java`、`MT.DATA`、`Loader_Recipes_Other.java`、`Loader_Recipes_Handlers.java`。没有搬用 GTM 代码。目标是补现有高科技设备的制造前置，不代表高科技、核能、生态等全蓝图完成。

## 本批实现

- 55 条工作台配方：LV–LuV 六级的电动机、泵、传送带、活塞、机械臂、信号发射器、传感器、力场发生器，共 48 条；另有四种 ULV 机械部件、ULV/LV 钢磁芯替代，以及铜电路布线。
- 等级结构材料依次为锡合金、镀锌钢、铝、不锈钢、铬、钛、铱（含 ULV）。电动机磁芯、绕组粗细、裸线/绝缘线、末影与下界材料均按对应等级区分。
- 泵同时使用螺丝刀和扳手；活塞使用螺丝刀；铜布线使用剪线钳。各工具按自己的 GT6 每次合成耐久消耗返回，损坏工具不能合成，预览不改动原工具。
- 123 条机器配方：3 条空电路板压制、3 条红宝石透镜激光布线、3 条布线压板、18 条电路零件压制、18 条装板、18 条焊料浴、48 条晶锭生长、12 条磁化。
- 电路板基材限制成品等级：铜最高 Good，金最高 Elite，铂最高 Ultimate。每块板需要四个对应零件。
- 焊料浴为 72 mB、64 ticks、0 GU/t。以 Ultimate 板为例，铅焊得 Elite、锡焊得 Master、焊锡合金得 Ultimate；低等级焊料不会凭空保留最高级成品。
- 硅、锗、红石合金、尼科林合金恢复晶锭与晶体板形态，未将半导体强行归为普通宝石。每种材料支持六种稀有气体及单个/九个批量生长：单个消耗小撮晶种、560 mB 熔体、1000 mB 气体，16 GU/t，72000 ticks。已有切割机配方负责晶锭到晶体板再到小晶体板；原版切割一块晶体板产八小块，有切割损耗，本批没有改成九块。
- 铁、钢、钕的锭、杆、长杆、螺栓恢复对应磁性形态的磁化配方。铁/钢 16 GU/t、钕 128 GU/t；时间按形态材料量折算。
- 橡胶、塑料补回锭、板、环等形态，接入现有挤压加工。没有赋予它们金属或可锻造属性。
- 配方可单独标记不消耗的输入。红宝石透镜按配方保留，普通以透镜作耗材的其他配方不受影响。并行只需一份透镜；同一种物品若同时是保留物与耗材，必须提供两份，防止重复匹配。

## 进游戏优先验收

1. 在 JEI 搜索 LV 电动机、泵、机械臂，再查看 HV/EV/LuV：确认材料、绕组宽度、磁芯、电路依次变化。泵的两件工具应均被扣耐久并留下。
2. 压制机制作空电路板、零件、装配板；对 Ultimate 板分别使用熔融铅、锡、焊锡合金，检查产物为 Elite/Master/Ultimate。机器界面能源单位继续使用 GU。
3. 激光刻蚀机放入四片铜/金/铂箔和一个红宝石透镜，确认产一份布线且透镜保留；抽走透镜后不能加工。
4. 结晶坩埚测试任一种晶锭配方。正常单批需 72000 ticks（20 TPS 下约一小时）；想快速验收可先用创造物品测试后续切割链，不要把长耗时误判为卡住。
5. 磁化机测试钢杆、钕杆；检查橡胶板、环与半导体晶锭的背包贴图及材料颜色。

- 材料注册、客户端模型查找、工具交互、容器/传感器等独立契约检查通过。
- 首轮启动检查发现红石合金缺晶种粉形态，后续配方加载检查发现铜布线的剪线钳注册名拼写错误，均已修正后重跑。
- 完整资源任务已执行；最后一次单文件 JSON 修正定向同步至构建资源，55 条配方与源码逐字节一致。最终复测使用 `runGameTestServer build -x processResources --offline --console=plain`。

没有启动可视客户端，JEI 排版、GPU 渲染和真实机器交互仍需上述游戏内验收。

本批的配方使用已移植的标准材料分支：铜、橡胶、红宝石透镜及三个石英粉种类。GT6 全部 ANY 材料替代、红色透镜替代、魔法/末影电路分支尚未全量展开。保留现有传送带双下划线注册 ID，避免破坏存档。

没有以普通电路冒充原始或量子电路：ULV 的机械臂/发射器/传感器/力场发生器及 ZPM 以上对应配方仍待独立原料链。多倍线缆制造与拆分、橡胶凝固和塑料成型的完整上游、全部形状模具制造路线仍需下一批核对补齐。本批不能认定完整生存闭环已完成。
