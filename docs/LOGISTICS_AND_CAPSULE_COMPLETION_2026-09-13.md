# 原版扩展器、桥接器与胶囊制造续批

本批继续第二批物流和第五批材料制造。参照 GT6 源码实现，没有引用 GTM 实现代码；没有构建 JAR。

## 六个新增物流方块

- 物品扩展器，原版 ID 30000：只提供物品库存访问。
- 流体扩展器，原版 ID 30001：只提供流体访问。
- 物品与流体扩展器，原版 ID 30002：同时提供上述两种能力。
- 物品桥接器、流体桥接器、混合桥接器，原版 ID 30500–30502：分别只转发物品、只转发流体、同时转发。

扩展器具有两个独立的六向朝向。外部从主面访问时，连接副面相邻容器；从其他面访问时，连接主面相邻容器。扳手调整主面，活动扳手调整副面，使用已有共用工具交互和渲染提示声明。两面可以相同，符合原版 `getValidSecondSides()` 默认规则。

桥接器没有可调整的主副面。它的每个面分别访问正对面的相邻容器，例如西面访问东边的箱子、顶面访问下面的罐。它不是把六面容器合并成一个大库存。

这六个方块都是访问转发器，不主动搬运、不缓存物品或流体。它们使用相邻容器实际暴露的对应面能力；模拟查询不消耗内容，不加载未加载区块。能力句柄在相邻容器被破坏或替换后重新解析目标；递归保护阻止两个扩展器互相指向时无限调用。

已补原版合成：钢机器外壳或双重钢机器外壳、钢中型流体管、琥珀金中型物品管、锤和扳手。合成工具保留并扣耐久，方块堆叠上限 16。外壳制造复用上一轮的焊接配方。

模型使用 GT6 `machines/extenders` 原始底图与叠层，世界和物品都染为钢色。扩展器全部 36 组主副方向都有对应模型；桥接器采用原版六面一致贴图。纹理原文件及 SHA-256 记录在 `tools/gt6_texture_sources.json`，模型和配方可以用 `tools/rebuild_source_extenders.py` 重建。

## 胶囊制造与回收

上一轮有 56 条挤压配方，覆盖 11 种材质。本批扩展为 **208 条，覆盖全部 40 种胶囊材质**：

- 12 种低热材质：8 种蜡、塑料、锡、锡合金、铝。锭、粉各产出 9 个胶囊，粒、小撮粉各产出 1 个；普通与低热模具均可使用，16 GU/t、64 或 8 ticks。
- 28 种高温材质：仅允许普通胶囊模具，96 GU/t。按 GT6 `RecipeMapHandlerPrefixForging.getCosts` 与 `OreDictMaterial.getWeight` 计算热量和质量相关耗时，最低 16 ticks；不是沿用低热材质的固定耗时。计算使用当前移植材料参数，材料物性全集仍需进一步核对。
- 新增 **40 条撕碎机回收配方**，每个空胶囊回收 1/9 材料单位的小撮粉。蜡/塑料按原版脆性材料耗时，其他材质按金属耗时并考虑工具品质。

机器配方匹配现在会区分空便携容器与装有流体的容器。即使只有 1 L，也不能按空壳回收或被其他空容器配方消耗；带明确流体 NBT 的输入仍按原有 NBT 匹配。物品类型不符时先退出，避免对所有不相关物品查询流体能力。

首轮测试发现锡合金等材料缺少原版规定的粉末形态。已恢复这组材料在 `MT.wax` 或 `G_INGOT` 中具备的粉末、锭和粒，使挤压和回收使用真实材料物品。没有用占位物品绕过缺失。

本批已统计的配方净增加 **198 条**：胶囊挤压从 56 增至 208（增加 152）、回收 40、物流工作台合成 6。不把材料形态恢复引出的其他自动配方计入这个数字。

## 纠正上一轮的 Ke 映射

GT6 `MT.Ke` 的材料是 **Trinium（材料 ID 1260）**，并非 **Kreknorite（8759）**。上一轮胶囊目录把它映射错了。

现在胶囊采用 Trinium 的颜色、耐温与制造材料，并补回 Trinium 的相关材料形态。为保留已经放置的方块和背包物品，注册 ID 仍保留 `gregtech:fluid_cell_kreknorite`；显示名已改为 Trinium 胶囊容器。`docs/capsule-cell-source.json` 已注明这是兼容旧 ID，不代表两种材料等价。

## runClient 测试清单

1. 创造栏或 JEI 搜索“扩展器”和“桥接器”，确认新增六种方块有钢色、正确贴图与配方。旧的基础/高级/精英/无线扩展器还在，不要把它们与本批新增的原版变体混淆。
2. 放一个物品扩展器，扳手把主面调朝箱子，其他面接物品管；活动扳手调整副面，测试从主面访问时是否改为访问副面箱子。试一次主面朝上、副面朝东。检查工具提示面和贴图的输入/输出面一致。
3. 同样测试流体扩展器和混合扩展器。物品专用型号不应被流体管当成罐接口；流体专用型号不应给物品管提供库存。
4. 在桥接器东西两边各放容器，北边再放一个。确认西面访问东容器、南面访问北容器；不会把三个容器合并或自动搬空。需要管道、漏斗等设备主动请求传输。
5. 传输中破坏并替换目标箱子/罐，检查旧物品不会凭空出现；把两个扩展器配置为循环指向，检查不卡死、不复制、不吞掉输入。
6. JEI 查看锡合金、钨、Trinium、Infinity 胶囊。锡合金应有低热模具路线；钨等高温材质不应有低热路线。普通模具在加工后保留。
7. 空胶囊放入撕碎机，检查产出一个同材质小撮粉；再试装水的胶囊，应不加工。清空后可以回收。
8. 旧存档中上一轮的“Ke/Kreknorite 胶囊”应仍存在，但名称和颜色改为 Trinium。
