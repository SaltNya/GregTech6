# 2026-10-07 / 桶物品的默认数据、实际挖取与回收

本批基线 `7f3fa3ce`。两个平台的 TankBlock 原先把完整方块存档写入每个掉落桶，包括默认温度、false 模式、0 进度和空储罐的容量字段。因此放过一次的空桶与新桶不能正常叠加，并被既有内容保护规则拒绝粉碎/坩埚回收。

只在原生桶的掉落物边界增加稀疏数据写出：删除实际默认温度、关闭模式、零发酵进度/时长，未染色 false 标记，以及无流体身份、数量零且容量仍为该桶默认值的储罐。Neo 只有非空数据才加类型 id 和 BLOCK_ENTITY_DATA。Forge 只移除类型确为 compound 且无内容的 ForgeCaps/ForgeData 外壳，非空或异常类型继续保留。世界保存和加载、同步、注册、配方、语言、通用 ItemMaterialRegistry 的保守保护规则及覆盖板挖取快照均未改。非默认温度、模式/进度、容量、实际流体、物流桶零数量过滤记忆、覆盖板及其他原生保存字段继续保留并阻止回收。
