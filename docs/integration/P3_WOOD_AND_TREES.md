# P3 — Wood, tree shapes, tree holes and crafting

The original saltnya 12-species catalog now lives in shared core. Neo registers the same 61 wood blocks (five per species plus the Blue Spruce slab), three rubber/maple/rainbowood holes, the original tree-hole entity and the surface-tree feature. One shared `TreeShapeRules` carries all nine original canopy algorithms, trunk-height rolls, replacement gates, rubber resin-hole placement and Blue Spruce podzol conversion. Both versions invoke it through a thin Minecraft world adapter. Shape and public helper identities used by the Forge baseline remain available.

The world abstraction follows masson's separation of placement from canopy calculations; comparison source hashes are recorded. Its nearby-hole tracker and alternate tree/material registries are not imported. The original baseline policy of placing one rubber resin hole is retained. brokestar's coconut sand-substrate gate is adopted through shared `TreeSpeciesRules` in both platforms. Baseline per-species decay boxes and refill gates are shared. Native leaf loot adapts the actual enchantment-holder and shears ability APIs; log tool clicks and hole tapping use native interaction hooks and existing hand-container transfer.

The original `GTWoodRecipes` table is shared byte-for-byte. Native crafting uses a reloadable built-in pack and the already registered tool-wear/non-mirroring serializer, retaining the original recipe IDs, counts and tool keys. The three treated-wood patterns are shared with the Forge loader. Vanilla/registered/treated wood machine-processing loaders are wired in the original relative order, using the existing unified materials and fluids. The original four cinnamonwood rod rows remain explicitly absent from the source catalog; no replacement material or recipe is invented. The surface feature's existing vanilla-biome mappings and lack of natural Rainbowood generation without its modded biome are retained.

196 model/blockstate/world-feature resources are moved from the integration's Forge resource directory into shared core; source snapshots are unchanged. Native wood tags, half-slab crafting and biome-loader namespace are adapted. Native rubber resin uses its original non-edible MultiItem identity; the following food wave supplies cinnamon bark's original food factory; the original cinnamon-dust fallback remains where that item is absent. Rendering appearances, complete harvesting/drop parity, tree generation in natural biomes and reload/old-save compatibility remain pending.

Source and adaptation records: `core/provenance/wood-trees-source-integration.json` and `core/provenance/wood-recipes-source-integration.json`. Authors, licenses and available source history remain preserved. There is no third-party relicensing.
