# 通用扩展器续批一：控制与红石

原版依据：`MultiTileEntityExtender`、`MultiTileEntityBridge` 及其 Controller 子类；注册 30255 / 30755。没有采用 GTM 代码。

## 完成

- 新增通用扩展器、通用桥接器。继承既有物品/流体转发，普通六种扩展器不会获得通用控制。
- 不锈钢染色、原版底图与叠层、36 种主副方向模型；两条原版布局制造配方，四重不锈钢机器外壳及管道、弹簧、转子、齿轮、电路前置。
- `MachineControl` 提供开关、运行/加工状态、原始进度。普通机器和继承此基类的加工多方块已接入；进度传感器也通过这个接口读取。
- 扩展器软锤控制主面机器；桥接器软锤控制点击面的对面机器。缺少目标时提示且不消耗耐久。每次操作重新找目标；拆除、替换、循环连接不缓存失效机器。
- 普通机器的停止状态保存为 `gt.control_stopped`，旧存档默认开启；停止时不继续加工/投放待交付产物，保留进行中的工作。覆盖板的开关条件也作用于进行中的加工。
- 红石按原版方向规则转发；比较器读取随库存改变更新；循环查询有重入保护，不加载未加载区块。

## 边界与人工验收

原版桥接器的弱红石方向与物品的直穿方向不同，严格保留其 `getRedstoneIncoming(OPOS[query])` 规则。请勿用物品传输朝向推断红石行为。

Forge 1.20.1 原生方块比较器 API 没有查询方向：通用桥接器对原生比较器暂输出六面读数最大值；扩展器之间的比较器查询保留方向。此处不是原版多方向比较器的完整还原。

runClient：检查两种方块模型和不锈钢颜色、JEI 合成；连接机器后软锤停启；让进度传感器隔着扩展器读加工；主面接红石检查其余面的输出、反向检查回传；木桶内增减物品检查比较器。核、引擎等独立机器在下一批继续接入。

完整覆盖板协议、物流核心、USB/HDD、无线和任意第三方能力并未因此完成。
